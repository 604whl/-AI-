## 赛道

裸辞 / 转行 / 失恋复盘 / 从 0 开始做自媒体

## 目标受众

25-35 岁经历转折期，情绪低落但想改变的人。

## 爆款角度

- 低谷到高光的 90 天复盘
- 差点放弃的那一周
- 双非/大龄/零基础逆袭叙事
- 收入从 0 到 X 的真实曲线（区间表述）

## 推荐结构

COMEBACK：叙事弧 + 行动清单 + 陪伴 CTA

## 禁忌

- 不贩卖焦虑（「你再不行动就完了」）
- 收入数据用「我的经历」避免普适承诺
