## 开篇 Hook

面了 12 场大厂 PM 面试，这 8 个问题出现率超过 80%。

## Q&A 要点

| 问题 | 回答框架 |
|------|----------|
| 自我介绍 | 背景→核心项目→为什么选我们（60 秒） |
| 最大挑战 | STAR：情境-任务-行动-结果 |
| 失败经历 | 坦诚 + 复盘 + 改进动作 |
| 为什么离职 | 正向动机，不吐槽前司 |
| 产品 sense | 选一个日常 App 说 3 个优化点 |
| 数据案例 | 用数字证明你的贡献 |
| 反问环节 | 问团队、业务、成长，别只问加班 |
| 薪资期望 | 给区间，留谈判空间 |
