# Prompt Rubric — 五维评分与内容类型判定标准

> 版本：`rubric-1.0.0`  
> 用途：作为系统 Prompt 与人工评测的统一标尺；每次分析记录应携带此版本号。

---

## 一、使用说明

1. **评分流程**：先识别 `contentType`（主类型 1 个，可带次要标签）→ 再按五维独立打分 → 综合 `viral` 非五维算术平均，需说明权重逻辑。
2. **输出要求**：每维 0–100 整数 + `reason` 一句（≤40 字，具体可验证）。
3. **人设影响**：仅影响 `conversion` 与 CTA/语气类 `issues`，不改变 CTR/收藏判定基准。
4. **封面**：有封面图时 CTR 维度须提及封面；无图时 CTR 仅评标题，并在 reason 注明「未含封面」。

---

## 二、五维评分 Rubric

### 2.1 CTR 潜力（ctr）

**定义**：用户在发现页/搜索列表中点击该笔记的概率。

| 分数档 | 标准 | 典型信号 |
|--------|------|----------|
| 90–100 | 强点击冲动：冲突+具体数字+身份标签+结果暗示齐全 | 「海投300份0面试」「藤校海归回国3个月上岸」 |
| 75–89 | 有明确钩子，缺 1 项强化要素 | 有焦虑但无数字；有 Offer 但标题平淡 |
| 60–74 | 主题清晰但同质化，像「经验分享」类万能标题 | 「留学生求职干货」「秋招注意事项」 |
| 40–59 | 信息模糊、无身份/无后果、纯名词堆砌 | 「求职攻略」「简历怎么写」 |
| 0–39 | 无关赛道、过长难扫读、无情绪无利益点 | 论文式标题、纯机构硬广名 |

**加分项（各 +5，上限 100）**：具体数字；海归/藤校/QS 等身份；时间限定（26届/倒计时）；对比结构（Before/After）。

**减分项（各 -5~-15）**：超过 20 字难扫读；emoji 堆砌掩盖信息量；标题正文严重不符。

**封面（有图时）**：大字关键词是否可读、人物/证件是否制造信任或好奇、配色是否与情绪匹配。

---

### 2.2 情绪传播（emotion）

**定义**：引发目标受众（留学生/海归/应届）共鸣、转发讨论、评论互动的能力。

| 分数档 | 标准 | 典型信号 |
|--------|------|----------|
| 90–100 | 情绪曲线完整：焦虑/不公→共鸣→希望；有第一人称真实感 | 被拒经历、文化冲突、家长压力、同辈对比 |
| 75–89 | 情绪明确但转折弱或偏说教 | 大量「你应该」少「我曾经」 |
| 60–74 | 信息为主，情绪点缀 | 清单体、百科体 |
| 40–59 | 冷冰冰或机构口吻过重 | 「本公司提供」「行业领先」 |
| 0–39 | 与受众无关或引发反感 | 嘲讽求职者、制造虚假恐慌 |

**垂类高共鸣主题**：身份焦虑（海归不值钱）、时间焦虑（签证/OPT/H1B）、同辈压力（同学都上岸了）、信息不对称（内推/隐藏规则）。

---

### 2.3 收藏价值（collect）

**定义**：用户愿意「先收藏后看」的实用密度与结构化程度。

| 分数档 | 标准 | 典型信号 |
|--------|------|----------|
| 90–100 | 可当工具书：时间线/清单/模板/对比表，步骤可执行 | 秋招时间轴、岗位投递表、面经 QA |
| 75–89 | 干货足但结构散，需用户自己整理 | 长文经验但无小标题 |
| 60–74 | 有 1–2 个可用点，整体偏故事 | 只讲经历不给方法 |
| 40–59 | 纯情绪宣泄或纯结果炫耀 | 只晒 Offer 无过程 |
| 0–39 | 无新信息、泛泛而谈 | 「要多投」「要Networking」 |

**类型加权参考**：时间线型/信息差型/面经型通常 collect 基准更高；纯 Offer 晒单若无方法论则 collect 通常 ≤70。

---

### 2.4 转化能力（conversion）

**定义**：引导私信咨询、加微信、点击主页服务入口的效力（须合规）。

| 分数档 | 标准 | 典型信号 |
|--------|------|----------|
| 90–100 | 信任链完整：人设/案例→痛点共鸣→低门槛 CTA→利益点清晰 | 「评论【时间线】领表」「私信【BG】帮看简历」 |
| 75–89 | 有 CTA 但偏硬或与人设不符 | 机构号过于销售；导师号缺专业背书 |
| 60–74 | 只有弱引导「有需要可以私信」 | 无具体钩子 |
| 40–59 | 全文无 CTA 或 CTA 与内容脱节 | 干货文突然卖课 |
| 0–39 | 违规承诺或严重伤信任 | 「保 offer」「100%上岸」 |

**人设差异（CTA 语气）**：

| 人设 | 推荐 CTA 风格 | 避免 |
|------|---------------|------|
| 机构号 | 资料领取、测评、公开课名额 | 过度个人故事冒充学长 |
| 导师 IP | 1v1 方向、案例拆解、预约咨询 | 硬广式群发话术 |
| 学长学姐 | 组队打卡、资料互助、经验答疑 | 机构官方腔 |

---

### 2.5 爆款概率（viral）

**定义**：综合该笔记在留学生求职垂类成为小爆款（互动显著高于账号均值）的可能性。

**计算原则（给模型）**：

```
viral ≈ 0.30*ctr + 0.25*emotion + 0.20*collect + 0.25*conversion
```

允许 ±8 分调整，须在 reason 说明：如「CTR 极高但收藏弱，偏昙花一现型爆款」「转化极强适合精准获客，爆款概率中等」。

| 分数档 | 含义 |
|--------|------|
| 85–100 | 具备冲爆款结构，建议优先发布或小幅润色 |
| 70–84 | 优质内容，优化 1–2 处可发布 |
| 55–69 | 需明显改写后再发 |
| 40–54 | 不建议直接发布 |
| 0–39 | 偏离赛道或存在合规/质量问题 |

## 三、六类内容类型判定标准

> 判定 **主类型 1 个**；若两种特征均强，选更能解释「用户为何点开」的类型，另一作为次要标签。

### 3.1 焦虑型（ANXIETY）

| 项 | 标准 |
|----|------|
| 核心 | 放大恐惧、不确定性、同辈压力、身份危机 |
| 标题信号 | 难、崩、寒冬、0 offer、学历贬值、回国失业 |
| 正文信号 | 痛点场景描写 > 解决方案；常含「我以为…没想到…」 |
| 非本型 | 若焦虑后给出完整可执行时间线且收藏点为主 → 偏时间线型 |

### 3.2 Offer 型（OFFER）

| 项 | 标准 |
|----|------|
| 核心 | 以录取/上岸/薪资/大厂 logo 为结果锚点建立信任 |
| 标题信号 | 上岸、offer、大厂、年薪、逆袭录取 |
| 正文信号 | 结果截图/学校公司名/时间线到 offer；转化导向强 |
| 非本型 | 仅有结果无过程且干货极少 → collect 低，主型仍为 OFFER |

### 3.3 信息差型（INFO_GAP）

| 项 | 标准 |
|----|------|
| 核心 | 「别人不知道我知道」— 隐藏规则、内推、渠道、政策 |
| 标题信号 | 很少有人知道、内推、隐藏、避坑、潜规则 |
| 正文信号 | 对比常识 vs 真相；列表化「N 个误区」 |
| 非本型 | 若主体为面试问答实录 → 面经型 |

### 3.4 面经型（INTERVIEW）

| 项 | 标准 |
|----|------|
| 核心 | 具体公司/岗位/轮次/题目的面试经历与答题思路 |
| 标题信号 | 面经、面试题、XX 厂、一轮/二轮、OA |
| 正文信号 | Q&A、考察点、准备建议、真实对话还原 |
| 非本型 | 无具体公司岗位仅泛泛「面试技巧」→ 信息差或焦虑 |

### 3.5 时间线型（TIMELINE）

| 项 | 标准 |
|----|------|
| 核心 | 按时间阶段组织求职动作，强调可照抄的节奏 |
| 标题信号 | 时间线、X月–X月、26届、倒计时、全程规划 |
| 正文信号 | 月份/周节点、每阶段任务、里程碑 |
| 非本型 | 仅文末一张时间表而正文是故事 → 主型看开篇钩子 |

### 3.6 逆袭型（COMEBACK）

| 项 | 标准 |
|----|------|
| 核心 | 低谷→转折→成功的叙事弧，强调反差与可复制动作 |
| 标题信号 | 从…到…、逆袭、重启、非科班、gap、被拒后 |
| 正文信号 | 明确 Before 状态、转折点、After 结果、反思总结 |
| 非本型 | 若逆袭主要靠晒 offer 无过程 → OFFER；有完整过程+反差 → COMEBACK |

### 3.7 类型判定决策树（简）

```
有具体公司岗位面试细节？ → 面经型
否则 有清晰月份/阶段节点表？ → 时间线型
否则 有强 Before/After 个人转折？ → 逆袭型
否则 以 Offer/上岸结果为标题核心？ → Offer型
否则 强调隐藏信息/规则/内推？ → 信息差型
否则 以恐惧/压力/同辈比较驱动？ → 焦虑型
```

## 四、结构拆解字段标准

| 字段 | 要求 |
|------|------|
| hook | 首屏 1–3 句如何留人；是否含冲突/数字/身份 |
| emotionArc | 起承转合各一句，或四段情绪词 |
| savePoints | 列出 1–5 个收藏理由（干货/模板/清单） |
| conversionPath | 痛点→共鸣→证据→行动 是否闭环 |
| cta | 现有 CTA 原文 + 强弱评价 + 改进方向 |

## 五、问题诊断（issues）规范

| severity | 条件 |
|----------|------|
| high | 直接影响发布决策：合规风险、标题严重误导、无 CTA 且目标是获客 |
| medium | 明显拉低 1–2 个维度 ≥15 分的问题 |
| low | 润色级：语气、排版、次要关键词 |

| category | 适用 |
|----------|------|
| ctr | 标题、封面 |
| emotion | 情绪、叙事 |
| collect | 干货、结构 |
| conversion | CTA、信任链 |
| compliance | 敏感词、绝对化承诺 |

每条须含可执行 `suggestion`，禁止空泛「写得更好一点」。

---

## 六、合规红线（触发 compliance issue）

- 绝对化：保 offer、100%上岸、 garantee 录取  
- 虚假权威：冒充官方、未标注广告  
- 敏感歧视：院校/国籍歧视性表述  
- 过度恐吓：制造不存在的政策恐慌  

输出须 `complianceWarnings[]`，不阻止分析但模块5 展示 Alert。
