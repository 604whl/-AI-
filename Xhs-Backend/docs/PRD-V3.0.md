## 一、项目背景

留学生求职市场竞争加剧，留学生求职机构、留学中介、Career Coach、求职导师及小红书运营团队普遍依赖小红书进行获客、品牌曝光、私域转化与课程/服务销售。

### 1.1 现存问题

| 问题 | 描述 |
|------|------|
| 爆文不可复制 | 不知道为什么爆 |
| CTR 不稳定 | 标题与封面效果波动大 |
| 转化率低 | 有流量但没人咨询 |
| 内容同质化 | AI 生成内容缺乏运营逻辑 |
| 缺少专业分析 | 不知道问题出在哪 |
| 选题困难 | 不知道今天发什么 |

### 1.2 市场缺口

市面 AI 产品多聚焦文案/标题/图片生成，**缺乏真正理解「留学生求职小红书运营逻辑」的分析型产品**。

### 1.3 项目目标

打造**专注留学生求职赛道的小红书 AI 运营助手**，帮助运营人员提升爆文率、CTR、收藏率与转化率，降低内容试错成本。

## 二、产品定位

| 维度 | 内容 |
|------|------|
| 产品名称 | 小红书留学生求职 AI 运营助手 |
| 产品定位 | 留学生求职赛道 AI 运营分析平台 |
| 核心价值 | 帮助运营打造高转化爆文（分析优先，生成辅助） |
| 目标用户 | 留学生求职机构 / 留学机构 / 求职 IP / 运营团队 |
| 产品形态 | Web AI 运营工作台（首版单人 SaaS） |
| 产品方向 | AI 运营分析 + AI 内容优化 |

**一句话**：面向留学生求职赛道小红书运营人员的 Web 工作台，用垂类运营逻辑做爆文诊断、评分与优化，辅以标题/正文生成与模板复用；首版单人使用，不接入自动发帖与平台 API。

## 三、目标用户与场景

| 用户 | 特点 | 核心诉求 | 优先级 |
|------|------|----------|--------|
| 留学生求职机构 | 依赖内容获客、高客单价 | 爆文率、咨询率、降试错 | P0 |
| 求职导师 / Career Coach | 强个人 IP、高频输出 | 曝光、专业人设、咨询转化 | P0（需人设字段） |
| 小红书运营团队 | 高频测试与复盘 | CTR、收藏、转化 | P0 |
| 新人运营 | 经验不足 | 套模板、学结构 | P1（模板库） |

### 3.1 典型使用场景

1. **发前优化（P0）**：粘贴待发标题/正文，获评分与修改建议后发布。
2. **标题 A/B（P0）**：按高 CTR / 焦虑型 / Offer 型批量生成标题选稿。
3. **竞品学习（P1）**：粘贴对标爆文，提炼可借鉴结构（非洗稿）。
4. **发后复盘（P1）**：录入真实互动数据，对比 AI 预判与实际表现。
5. **模板快产（P1）**：按 Offer/焦虑/信息差等结构一键填参生成。

## 四、产品原则（开发前共识）

1. **分析 > 生成**：P0 必须让用户感到「懂留学生求职小红书」；生成是分析结果的延伸。
2. **人工在环**：所有输出可编辑、可导出；不承诺自动发帖。
3. **输入务实**：MVP 以标题 + 正文 + 封面图为主；竞品/已发笔记优先粘贴 + 截图，链接解析放 P1。
4. **可复盘**：已发内容支持录入曝光/点赞/收藏/私信咨询数（P1）。
5. **合规兜底**：输出侧敏感词与夸大承诺提示（P0 轻量规则）。

## 五、功能分期（P0 / P1 / P2）

> V2.0 第五章「全部 MVP」与第十三章分期存在冲突；**V3.0 以本节为准**。

### 5.1 P0 — 首版可交付

| 模块 | 功能点 | 说明 |
|------|--------|------|
| 工作台首页 | 新建分析、最近记录、快捷标题生成 | — |
| 分析任务 | 场景：草稿优化 / 已发复盘（仅录入，深度对比 P1）/ 竞品学习（基础解析 P0，深度对标 P1） | 见 5.4 |
| 内容输入 | 标题、正文、封面图（可选） | 标题与正文至少填一项组合 |
| 人设 | 机构号 / 导师 IP / 学长学姐 | 影响语气与 CTA |
| 爆文解析 | 内容类型 + 结构拆解 | 六类类型；Hook/情绪/收藏点/转化路径/CTA |
| 爆文评分 | 五维打分 + 理由 | CTR、情绪、收藏、转化、爆款概率 |
| 问题诊断 | 可执行问题列表 | ≥3 条 |
| 优化建议 | 标题/结构/情绪/CTA | 含原句→优化句示例 |
| 一键优化稿 | 完整改写稿 | 可编辑、复制 |
| 标题生成 | 5–10 条/次 | 按目标与类型 |
| 历史记录 | 列表与详情回看 | 账号维度 |
| 基础账号 | 注册登录、用量统计 | 为付费预留 |
| 合规提示 | 敏感词/绝对化话术 | 轻量规则 |

**P0 不做**：自动发帖、达人库、ROI 预测、团队协作、AI 配图、Agent 全自动运营。

### 5.2 P1 — 增强留存与闭环

| 模块 | 功能点 |
|------|--------|
| 已发复盘 | 链接/截图 + 实际数据；AI 对比预判 vs 实际 |
| 竞品对标 | 可借鉴点 / 勿照搬点；结构拆解 |
| 正文生成 | 五段式爆文 + 基于当前分析一键写正文 |
| 模板库 | 分类模板 + 填参生成 |
| 封面辅助 | 封面文案与构图建议（不生图） |
| 导出 | Markdown / 纯文本 |

### 5.3 P2 — 壁垒与增长

| 模块 | 功能点 |
|------|--------|
| 热门选题 | 热点标签、选题卡片、关键词 |
| RAG 知识库 | 垂类爆文案例、高 CTR 标题库、转化话术 |
| 行业日历 | 秋招/春招/H1B 等节点与选题包 |
| 付费与团队 | 订阅/按次；多席位与共享模板 |

### 5.4 P0 场景能力边界

| 场景 | P0 | P1 |
|------|----|----|
| 草稿优化 | 完整分析+评分+优化 | — |

| 竞品学习 | 同草稿分析流程 | 可借鉴/勿照搬专项模块 |

## 六、核心功能说明

### 6.1 爆文解析系统

**输入**：标题、正文、封面截图（可选）。

**输出**：

- **内容类型**：焦虑型 / Offer 型 / 信息差型 / 面经型 / 时间线型 / 逆袭型（判定标准见 [prompt-rubric.md](./prompt-rubric.md)）。
- **结构分析**：Hook、情绪曲线、收藏点设计、转化路径、CTA。
- **问题定位**：如标题缺冲突、情绪不足、缺身份认同、收藏价值不足。

### 6.2 爆文评分系统

| 维度 | 含义 |
|------|------|
| CTR 潜力 | 是否容易被点击 |
| 情绪传播 | 是否容易引发共鸣 |
| 收藏价值 | 是否容易被收藏 |
| 转化能力 | 是否容易引导咨询 |
| 爆款概率 | 综合判断 |

输出形式：0–100 分 + 一句原因（Rubric 见 [prompt-rubric.md](./prompt-rubric.md)）。

### 6.3 AI 优化建议（核心付费点）

- 标题优化（原句 → 优化句）
- 内容结构优化
- 情绪优化
- CTA 优化
- **生成优化稿**按钮

### 6.4 标题生成

用户选择目标：高 CTR / 高收藏 / 高转化 / 焦虑型 / Offer 型 / 信息差型等；输出 5–10 条标题。

### 6.5 正文生成（P1）

五段结构：Hook → 问题放大 → 真实经历 → 结果展示 → CTA。

### 6.6 模板库（P1）

Offer 晒单、焦虑型、信息差型、面经型、时间线型；一键套模板 + AI 填参。

### 6.7 热门选题（P2）

当前热点 + 推荐方向 + 热门关键词。

## 七、用户故事与验收标准

### US-01 发前优化（P0）

**作为**机构运营，**我希望**粘贴待发标题和正文并得到评分与修改建议，**以便**降低试错。

| 验收项 | 标准 |
|--------|------|
| 响应时间 | 30 秒内返回完整报告（P95 < 45s） |
| 评分 | 五维各含 0–100 分与一句原因 |
| 诊断 | ≥3 条可执行问题 |
| 建议 | ≥3 条优化建议 |
| 优化稿 | 含明确 CTA，可与原文比对 |

### US-02 标题批量试错（P0）

**作为**运营，**我希望**按目标类型生成多标题，**以便** A/B 选稿。

| 验收项 | 标准 |
|--------|------|
| 数量 | 单次 ≥5 条 |
| 相关性 | 与正文主题一致 |
| 垂类元素 | 至少 1 个（留学生/海归/offer/时间线等） |

### US-03 竞品学习（P1）

**作为**运营，**我希望**分析对标爆文并提炼可复用结构，**以便**选题和框架借鉴。

| 验收项 | 标准 |
|--------|------|
| 输出 | 可借鉴点 / 勿照搬点 + 类型 + 结构拆解 |
| 限制 | 不输出整篇洗稿 |

### US-04 发后复盘（P1）

**作为**运营，**我希望**录入真实互动数据，**以便**知道 AI 判断哪里准、哪里偏。

| 验收项 | 标准 |
|--------|------|
| 对比 | AI 预判维度 vs 实际表现文字对比 |
| 建议 | ≥3 条下一步优化建议 |

### US-05 导师人设（P0 轻量）

**作为**求职导师，**我希望**设定人设后建议语气一致，**以便**不破坏 IP。

| 验收项 | 标准 |
|--------|------|
| 差异性 | 机构号 vs 导师 IP 下 CTA 与语气建议明显不同 |

## 九、AI 能力需求（产品层）

### 9.1 分析输出契约

结构化 JSON，字段定义见 [api-schema/analysis-response.schema.json](./api-schema/analysis-response.schema.json)。

### 9.2 Prompt 体系

- **系统层**：垂类运营专家 + 评分 Rubric  
- **任务层**：解析 / 评分 / 诊断 / 优化 / 生成  
- **风格层**：焦虑 / Offer / 信息差 / 面经 / 时间线  

每次分析记录 **Prompt 版本号**，便于 A/B 与回归。Rubric 见 [prompt-rubric.md](./prompt-rubric.md)。

### 9.3 封面图（P0）

- 有图：多模态定性点评（关键词、对比度、情绪匹配）  
- 无图：仅标题正文评分，UI 提示上传封面可提升 CTR 分析准确度  

### 9.4 RAG（P2）

种子 50–200 篇垂类爆文；P0 评测集见 [seed-cases.md](./seed-cases.md)。

## 十、非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 分析 P95 < 45s；标题生成 < 20s |
| 安全 | 用户内容隔离；图片私有存储；日志脱敏 |
| 合规 | 敏感词提示；禁止默认输出「保 offer」「100% 上岸」等绝对化话术 |
| 可用性 | 报告模块可折叠；移动端浏览器可读 |
| 可观测 | 任务类型、耗时、模型、Prompt 版本、优化稿采纳点击 |

## 十一、商业化（需求占位，MVP 可不实现支付）

| 免费 | 付费（建议） |
|------|----------------|
| 每日 3 次完整分析 | 无限分析 + 优化稿 |
| 标题生成限次 | 正文生成 + 模板库 |
| 基础评分 | 竞品对标 + 复盘对比 |

**核心付费点**：优化建议 + 优化稿 + 深度诊断。

---

## 十二、成功指标

**定性**：首次用户访谈 ≥70% 认可「懂留学生求职小红书运营」。

**定量（上线后 4 周）**：

- 分析任务完成率 > 60%  
- 优化稿按钮点击率 > 30%  
- 7 日留存 > 25%  
- （P1）愿意录入发后数据用户占比 > 20%

1. 统一 P0/P1/P2，P0 聚焦分析闭环 + 标题 + 历史。
